Caso de estudio

PROYECTO DE ANÁLISIS Y MODELAMIENTO

Análisis Predictivo para la Evacuación durante Incendios Forestales en Chile

Proyecto orientado al análisis de datos de incendios forestales y al desarrollo de un modelo predictivo capaz de identificar escenarios o áreas que podrían requerir evacuación.

01

El desafío

Los incendios forestales generan información heterogénea proveniente de distintas fuentes geográficas y temporales.

El proyecto busca transformar estos datos en información útil para analizar patrones y construir un modelo de clasificación asociado a la necesidad de evacuación.

02

Metodología

  • Preparación de datos Limpieza, transformación y exploración utilizando Pandas.
  • Análisis espacial Integración y análisis de información geográfica mediante GeoPandas.
  • Feature engineering Construcción y selección de variables relevantes para el modelo.
  • Machine Learning Desarrollo de un modelo de clasificación utilizando Scikit-learn.
  • Variable objetivo Clasificación mediante la variable necesita_evacuacion.
  • Evaluación Evaluación del comportamiento y desempeño del modelo predictivo.
